# insta-viral

اسکیل تحقیق. بقیه‌ی بسته می‌نویسن؛ این یکی می‌ره و نگاه می‌کنه. ماهی یه بار اجراش کن، نه هر روز. فرمول‌ها یه فصل دوام میارن.

یه ابزار تو این پوشه هست و اجرا می‌شه:

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

## ایده‌ای که این کار رو می‌ارزونه

**ویوی خام مدرک نیست.** حسابی با دو میلیون فالوور که ۴۰۰ هزار ویو گرفته، یه سه‌شنبه‌ی آروم داشته. حسابی با چهار هزار فالوور که ۴۰۰ هزار ویو گرفته، یه چیزی پیدا کرده، و اون چیز قابل کپیه.

پس همه‌چی اینجا با **ضریب جهش** رتبه‌بندی می‌شه: ویو تقسیم بر میانه‌ی ویوی اخیر خود همون حساب. بالای ۳ برابر یعنی سیگنال. زیر ۱٫۵ برابر یعنی روز عادی اون حساب، و هیچی یادت نمی‌ده، هر چقدر هم عددش بزرگ به نظر برسه.

حساب‌هایی جمع کن که **حداکثر حدود ۱۰ برابر کاربر** فالوور دارن. فرمولی که تو دو میلیون فالوور جواب می‌ده، اغلب به‌خاطر همون دو میلیون جواب می‌ده.

## قدم ۱: انتخاب حساب‌ها

از کاربر ۶ تا ۱۲ حساب بخواه، یا پیشنهاد بده و تأیید بگیر:

- **۴ مستقیم:** همون حوزه، همون پیشنهاد، یه کم جلوتر.
- **۴ همسایه:** حوزه‌ی دیگه، همون مخاطب. فرمت‌ها از اینجا قرض گرفته می‌شن قبل از اینکه کسی تو حوزه داشته باشدشون.
- **۲ تا ۴ خیلی بزرگ:** فقط برای فرمت، هیچ‌وقت برای تعداد پست یا لحن.

**نکته‌ی فارسی:** حساب‌های انگلیسی‌زبون رو هم بیار. خیلی از فرمت‌ها چند ماه زودتر اونجا جواب دادن و هنوز تو فارسی کسی نساختدشون. فرمول‌ها دوزبانه دسته‌بندی می‌شن.

از کاربر بخواه **Saved** خودش رو هم باز کنه. سریع‌ترین و مرتبط‌ترین مجموعه‌ایه که وجود داره، و با سلیقه‌ی خودش فیلتر شده.

## قدم ۲: برو نگاه کن

از هر ابزار مرورگری که این جلسه واقعاً داره استفاده کن: مرورگر داخل اپ، افزونه‌ای که به کروم خود کاربر وصله، یا کنترل کامپیوتر. API لازم نیست، چون حجمش اونقدر کمه که خوندنی‌ه.

**دسترسی از ایران:** اینستاگرام تو ایران فیلتره. مرورگری که استفاده می‌کنی باید از فیلترشکن کاربر رد بشه. اگه مرورگر داخل اپ به اینستاگرام نمی‌رسه، یه پنجره‌ی کروم با پروکسی فیلترشکن (مثلاً `--proxy-server=http://127.0.0.1:PORT`) و افزونه‌ی Claude in Chrome جواب می‌ده.

**قانون‌هایی که مذاکره‌بردار نیستن:**

- **هیچ‌وقت به‌جای کاربر وارد اینستاگرام نشو و هیچ‌وقت رمز نخواه.** اگه صفحه‌ای ورود لازم داره، کاربر خودش واردش شده. مرورگرش رو با حضور خودش هدایت کن، یا ازش بخواه بچسبونه.
- **این خوندنه، نه اسکرپ کردن.** ده حساب، از هر کدوم ده‌دوازده ریلز، با سرعت آدم. جمع‌آوری خودکار با حجم بالا خلاف قوانین اینستاگرامه و حساب رو محدود می‌کنه. کرالر نساز، از سرویس اسکرپ استفاده نکن، و این کار رو تو پس‌زمینه تکرار نکن.
- **فرمول رو کپی کن، نه ویدیو رو.** شکل هوک، ساختار، طول، الگوی کات‌ها. نه متنشون، نه صداشون، نه تدوینشون. هر ردیف فایل الگو رو به حساب خودش نسبت بده.

**برای هر ریلز چی برداری**، با کلمه‌های خود سازنده:

| ستون | توضیح |
| --- | --- |
| account / حساب | آیدی |
| followers / فالوور | از پروفایل |
| median / میانه | ۱۲ ریلز آخر رو نگاه کن و ویوی وسطی رو بردار |
| views / ویو | همین ریلز |
| hook / هوک | خط اول، گفتاری یا روی صفحه، کلمه‌به‌کلمه حتی با غلط‌هاش |

میانه مهم‌ترینه. بدونش برگشتی به رتبه‌بندی با فالوور، که این اسکیل برای جلوگیری ازش ساخته شده.

**وقتی اینستاگرام به اندازه‌ی کافی نشون نمی‌ده:** همون دستور زبون هوک روی YouTube Shorts هم جواب می‌ده، جایی که ویو و زیرنویس عمومیه و ورود لازم نیست:

```bash
# ویوی شورت‌های یه کانال (از ایران: --proxy http://127.0.0.1:PORT اضافه کن)
python3 -m yt_dlp --flat-playlist --playlist-end 40 -J "https://www.youtube.com/@HANDLE/shorts" > channel.json

# خط اول گفتاری یه شورت، از زیرنویس خودکار
python3 -m yt_dlp --skip-download --write-auto-subs --sub-langs "fa.*,en.*" \
  --sub-format json3 -o hook "https://www.youtube.com/watch?v=VIDEO_ID"
```

هر کلمه‌ی زیرنویس با زمان زیر ۳ ثانیه رو بردار. اون هوکه، همون‌طور که گفته شده، نه نوشته شده.

## قدم ۳: رتبه‌بندی

یه فایل جدا‌شده با تب، با یه خط سرستون (فارسی یا انگلیسی):

```
حساب	فالوور	میانه	ویو	هوک
@someone	48٬000	11٬000	412٬000	هیچ‌کس بهت نمی‌گه ۳۰ تا ریلز اولت قراره شکست بخوره
```

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

ضریب جهش رو حساب می‌کنه، فرمول هوک رو با همون ۲۷ فرمولی که `/insta-reel` ازشون می‌نویسه اسم‌گذاری می‌کنه، هر هوک رو با `hookscore.py` امتیاز می‌ده، و می‌گه یک‌سوم بالا با یک‌سوم پایین چه فرقی داره.

## قدم ۴: بگو یعنی چی، با احتیاط

فقط سه چیز گزارش کن:

1. **کدوم فرمول‌ها تو یک‌سوم بالا بیشتر از سهمشونن**، با تعداد. دو فرمول که هر کدوم چهار بار تو شش حساب اومدن یعنی یافته. یکی که دو بار اومده، نه.
2. **یک‌سوم بالا از نظر ساختاری چه وجه مشترکی دارن** که یک‌سوم پایین نداره: طول هوک، اینکه پرداختش تصویریه یا نه، فریم اولش حرکت داره یا نه، درخواست کجاست.
3. **ردیف‌های دسته‌بندی‌نشده.** هر هوکی که اسم نگرفته یا نویزه یا فرمولیه که هنوز تو `hooks.json` نیست. با دست بخونشون. ارزشمندترین ستون خروجی همینه.

بعد اندازه‌ی نمونه و میزان اطمینان رو ساده بگو. چهل ریلز از شش حساب یه ادعا رو پشتیبانی می‌کنه. دوازده تا نه، و گفتنش فرق تحقیق با فال‌بینیه.

## قدم ۵: تبدیلش کن به چیزی که بشه ضبطش کرد

برای سه فرمول بالا، **نسخه‌ی خود کاربر** رو بنویس: داستان خودش، عدد خودش، تو شکلی که داره جواب می‌ده. هر کدوم رو با شماره‌ی فرمول به `/insta-reel` بده.

هیچ‌وقت «یه ریلز مثل این بساز» تحویل نده. خط هوکی تحویل بده که فردا بشه گفتش.

```
  11.2x  hook 79  #9  بدزدش                @acct_c    180,000  (میانه 16,100)

چی بیشتر از سهمش اومده
  #3  ×۵ تو یک‌سوم بالا، ۰ تو پایین
  طول میانه‌ی هوک    ۸ کلمه بالا، ۱۹ پایین

دسته‌بندی‌نشده (۶)
  دو تاش یه شکل دارن که تو hooks.json نیست: هوکی که با خوندن کامنت یکی دیگه شروع می‌شه.

نسخه‌ی تو
  #3  «هیچ‌کس بهت نمی‌گه که ۲۰ تا پیشنهاد اولت قراره رد بشه.»
```

فایل الگو رو تو `~/.claude/instagram/swipe.md` بنویس. `/insta-reel` و `/insta-plan` هر دو می‌خوننش.

این اسکیل هیچی منتشر، فالو، لایک یا دایرکت نمی‌کنه. فقط می‌خونه.
